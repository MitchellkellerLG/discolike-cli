    @click.command("validate")

    Command pipeline (per D-14):
    1. `client = get_client(ctx)`, `cli_ctx = _get_context(ctx)`
    2. `domains = read_domains(input_file, domain)` then `validate_domain_count(domains)`
    3. If `web_search and len(domains) > 50`: `cli_ctx.output.warning(f"Web search on {len(domains)} domains -- this will significantly increase cost.")`
    4. Pre-flight estimate: `estimate = cli_ctx.cost_tracker.estimate("validate/icp", len(domains))`. Display estimate via Rich Table to stderr showing domain count, context mode, web_search, estimated cost.
    5. Confirm gate: if not `auto_confirm` and `sys.stdin.isatty()`: `click.confirm("Proceed?", default=False, abort=True)`. If not `auto_confirm` and not `sys.stdin.isatty()`: raise `click.UsageError("--yes flag required in non-interactive mode")`
    6. Build params: `{"icp_text": icp_text, "domains": domains, "context_mode": context_mode}`. Add `"web_search": True` if flag set.
    7. Submit: `submit_resp = client.validate_icp_submit(params)`
    8. Save task: `cli_ctx.cache.save_task(submit_resp["task_id"], "validate/icp", json.dumps(params))`
    9. Poll: `task_mgr = AsyncTaskManager(client, cli_ctx.cache)` then poll with `cli_ctx.output._stderr.status(f"Validating {len(domains)} domains...")`
    10. Normalize results: API returns dict keyed by domain -> flatten to list of dicts `[{"domain": k, **v} for k, v in result["results"].items()]`
    11. Sort with compound key (per D-04):
        ```python
        _FIT_ORDER = {"yes": 0, "partial": 1, "no": 2}
        _CONF_ORDER = {"high": 0, "medium": 1, "low": 2}
        def _sort_key(row):
            fit = row.get("Fit", "no").lower()
            conf = row.get("Confidence", "low").lower()
            if fit == "no":
                return (2, {"high": 2, "medium": 1, "low": 0}[conf])
            return (_FIT_ORDER.get(fit, 2), _CONF_ORDER.get(conf, 1))
        ```
    12. Render: `cli_ctx.output.render(sorted_rows, title="ICP Validation Results", columns=["domain", "Fit", "Confidence", "Reasoning"], cost=cli_ctx.cost_tracker.last_call)`
